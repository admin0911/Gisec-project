Train & compare

Compare clean reference and after cleaning. A before-cleaning model is also trained when the input differs from the clean reference. All use the same model, seed, epochs and separate CIFAR-10 test set.

New runs reserve 10% of selected IDs as clean demo validation, excluded from every model’s training. The official test set remains separate. 20 epochs is a starting budget, not a convergence guarantee.

Benchmark runs seeds 42, 43 and 44. The epoch choice sets the reference model’s update budget; other models receive the same number of updates. Allow roughly three times the single-seed runtime.

Uses the CPU and can take a while on the full dataset. Keep the server running.
